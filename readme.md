# AI Assistant Prototypes

A monorepo containing multiple AI-powered educational and productivity assistant applications.

## Projects

This repository contains five specialized AI assistant prototypes:

### 1. Course-Wise Assistant

An intelligent course management system with features like:

- Course creation and management
- Syllabus tracking
- Performance analytics
- Practice center and PYQ analysis
- Group study features
- Bangla voice assistant
- Study path recommendations
- Gamification profile

### 2. Math Solver

A mathematics problem-solving assistant designed to help students solve and understand mathematical problems.

### 3. Medical Study Assistant

A specialized assistant for medical students to aid in their study and learning process.

### 4. Research Assistant

A tool to help with research tasks, literature review, and academic writing.

### 5. Text Assistant

A general-purpose text processing and writing assistant.

## Tech Stack

- **Frontend**: Next.js, TypeScript, React
- **UI Components**: Shadcn/ui
- **Styling**: Tailwind CSS
- **Package Manager**: pnpm
- **Monorepo Structure**: Each project contains client and server directories

## Structure

```
├── course-wise-assistant/
├── math-solver/
├── medical-study-assistant/
├── research-assistant/
└── text-assistant/
```

Each project follows a similar structure:

- `client/` - Next.js frontend application
- `server/` - Backend server implementation

## Getting Started

Navigate to individual project directories to run specific assistants. Each project has its own `README.md` with detailed setup instructions.

## Development

This is a thesis project exploring different applications of AI assistants in educational and productivity contexts.


### Information
- Conduct six FGD sessions in Phase 1

- Identify prototype ideas from the FGD sessions

- Validate the FGD findings through a nationwide survey

- Develop low-fidelity prototypes and conduct prototype-specific FGD sessions

- Collect feedback and refine the designs into mid-fidelity prototypes

- Conduct FGD sessions using the actual frontend designs

- After gathering feedback, develop high-fidelity, interactive prototypes and perform lab usability testing
